# Life Tracker PWA — public-safe version v3

This repository is safe to publish because the default checklist is generic: Habit 1–8.
Your real checklist and daily data are added later on your phone and stored locally in browser localStorage.

## Upload these files
- index.html
- styles.css
- app.js
- sw.js
- manifest.webmanifest
- icon-192.png
- icon-512.png
- README.md
- .gitignore
- sample-config-public-safe.json

## Do not upload
- exported JSON backups
- exported CSV files
- private notes
- screenshots with personal data

## Update without losing data
Keep the same GitHub Pages URL/repository.
Replace files with a newer version.
Open the app on iPhone and press Settings -> Reload app update.
Export Full JSON before updating just in case.
